# Dawood M D — Portfolio

A responsive, static portfolio website designed for GitHub Pages. The site highlights experience in industrial client requirements, data science, AI/ML, analytics, and product-oriented problem solving.

## Preview locally
Open `index.html` in a browser. No build step or package installation is required.

## Publish with GitHub Pages
1. Create a **public** repository named `Dawoodsdatalife.github.io` under the GitHub account `Dawoodsdatalife`.
2. Upload the contents of this folder to the repository root (make sure `index.html` is at the root).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. Wait for the deployment to complete. GitHub Pages will show the published URL in the Pages settings.

Official guide: https://docs.github.com/en/pages/quickstart

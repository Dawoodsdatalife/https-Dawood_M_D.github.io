# Publish your portfolio with GitHub Pages

## Website repository
1. Sign in to GitHub as **Dawoodsdatalife**.
2. Create a **public** repository named exactly `dawoodsdatalife.github.io`.
3. Upload `index.html`, `case-study.html`, `styles.css`, `script.js`, `.nojekyll`, and the `assets/` folder to the repository root.
4. Commit to the `main` branch.
5. Open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, then Save.

Your site URL will be: https://dawoodsdatalife.github.io/

## GitHub profile README
1. Create a separate **public** repository named exactly `Dawoodsdatalife`.
2. Add the supplied `README.md` to its root and commit.
3. GitHub will show it on your profile because the repository name matches your username.

## Before publishing
- Replace the project links (they point to your GitHub profile) with each project's public repository URL.
- Be ready to explain how each metric was measured (82% accuracy, 8% churn reduction, 25% efficiency, 8% throughput).
- The case study is a proposed plan with pilot targets. Keep it labeled that way.
- Fonts load from Google Fonts online. The site is static and needs no build tools.

## Local preview
Open `index.html` in a browser. Edit `index.html` and `case-study.html` for content, `styles.css` for appearance, and `script.js` for interactions.
